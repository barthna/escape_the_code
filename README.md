# Escape The Code 🎮🔒

An interactive coding-based escape room experience where players solve logical challenges and write Python code to unlock clues and escape! 

This project was built collaboratively as a **team project** and successfully **presented** as a concept and functional prototype.

---

## 📽️ Project Concept & The Unity Game
The video file **`escape_the _code_project_idea.mp4`** included in this repository showcases the core design of our game built using **Unity**. 

* **Unity Simulation**: While the repository includes a video demonstration, the actual game is designed in Unity as an interactive environment.
* **Interactive Gameplay**: Players can explore a virtual room, click on various elements/objects in the environment to discover clues, and solve coding puzzles directly in-game to progress and escape.

---

## 🌐 Web-Based Playground
In addition to the Unity game concept, this repository contains a web-based prototype designed with:
* **HTML5 & CSS3**: Clean, responsive layout with dark-themed terminal aesthetics.
* **Pyodide**: Runs Python code directly in the browser using WebAssembly—no backend server required!
* **CodeMirror**: A rich, in-browser code editor with syntax highlighting for Python.

---

## 📁 Repository Structure

* **`index.html`**: The main coding workspace featuring the Python execution sandbox.
* **`first.html` / `que.html`**: Level selection menus (Basic vs. Advanced tracks).
* **`escape_the _code_project_idea.mp4`**: Unity-built interactive gameplay demonstration video.
* **`escape the code ppt.pptx`**: The official presentation deck used during the project showcase.
* **`images/`**: Graphics and UI design assets.

---

## 🚀 Key Features

* **Multiple Difficulty Levels**: Choose between *Basic* and *Advanced* paths to test your skills.
* **Interactive Environment**: Click-to-solve puzzles (shown in the Unity demo video).
* **Live Compilation**: Instant feedback on your Python code inside the browser.
* **Sound Effects**: Immersive audio cues to enhance gameplay.
