# Escape The Code 🎮🔒

An interactive, puzzle-solving educational game designed to teach coding concepts (specifically Python) through a gamified escape room experience! 

This project was built collaboratively as a **team project** and successfully **presented** as a concept and functional prototype.

---

## 💡 The Core Concept: Learn Coding by Solving Puzzles
The fundamental idea of **Escape The Code** is to make learning programming fun and intuitive:
* **Explore & Find (ढूँढो)**: Players must search the interactive room/environment to locate hidden clues, objects, and coding challenges.
* **Solve & Unlock (सुलझाओ)**: Once a question or puzzle is found, players write and run Python code to solve the challenge.
* **Learn Coding (कोडिंग सीखो)**: By tackling these progressive logical challenges, players learn core programming concepts in a hands-on, engaging way.
* **Escape**: Successfully solving all the coding puzzles unlocks the door and allows the player to escape the room.

---

## 📽️ Project Concept & The Unity Game
The video file **`escape_the _code_project_idea.mp4`** included in this repository showcases the core design of our game built using **Unity**. 

* **Unity Simulation**: While the repository includes a video demonstration, the actual game is designed in Unity as an interactive 3D/2D environment.
* **Interactive Gameplay**: Players can explore a virtual room, click on various elements/objects in the environment to discover clues, and solve coding puzzles directly in-game to progress and escape.

---

## 🌐 Web-Based Playground
In addition to the Unity game concept, this repository contains a web-based prototype designed with:
* **HTML5 & CSS3**: Clean, responsive layout with dark-themed terminal aesthetics.
* **Pyodide**: Runs Python code directly in the browser using WebAssembly—no backend server required!
* **CodeMirror**: A rich, in-browser code editor with syntax highlighting for Python.
